# Blazor Color Picker Component Sample

A sample Blazor WebAssembly application demonstrating how to integrate and configure the [Blazor Color Picker](https://www.syncfusion.com/blazor-components/blazor-color-picker) component with various customization options.

## Overview

This repository demonstrates best practices for using the Blazor Color Picker component in a Blazor WebAssembly application. The sample includes various configurations and features such as:

- **Multiple color picker modes** (Palette mode with custom styling)
- **Preset color palettes** (Custom color groups with predefined colors)
- **Real-time color selection** (Live preview with event handling)
- **Inline color pickers** (Display without input fields)
- **Circular tile styling** (Modern UI with custom CSS)

The application is built on .NET 10 with Blazor components and includes sample pages to demonstrate the Color Picker functionality.

## Features

- **Palette Mode Color Picker** - Interactive selection with predefined color palettes
- **Custom Preset Colors** - 60+ built-in custom colors organized by color groups
- **Real-time Color Preview** - Live visual feedback as users select colors
- **Inline Display** - Color picker without input fields for cleaner UI
- **Circular Tile Styling** - Modern circular color tiles with custom CSS
- **Event-Based Updates** - Reactive color selection with change event handling
- **Responsive UI** - Works seamlessly across all screen sizes
- **Zero Configuration** - Works out of the box with sensible defaults

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/create-blazor-color-picker-component-in-blazor-webassembly-app.git
cd create-blazor-color-picker-component-in-blazor-webassembly-app
cd ColorPickerSample
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
